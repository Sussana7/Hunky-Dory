# Hunky-Dory 🍔

**Hunky-Dory** is a responsive food ordering website built with HTML, CSS, and JavaScript. It allows users to explore a menu, view images, read customer reviews, and place food orders — all from a sleek and user-friendly interface.

### ✨ Live Demo

🔗 [View Hunky-Dory Live](https://hunkydory1.netlify.app/)

## 🌟 Features

- 📱 **Mobile Responsive**: Optimized for all screen sizes.
- 📋 **Dynamic Menu**: Browse through delicious food options with images.
- 🛒 **Order Functionality**: Order your favorite dishes with ease.
- 💬 **Customer Reviews**: Read feedback from other food lovers.
- 🔗 **Navigation Links**: Smooth and intuitive scrolling across sections.

## 🛠️ Technologies Used

- **HTML5** – Semantic structure and layout
- **CSS3** – Custom styling and responsive design
- **JavaScript (ES6)** – Order logic and interactivity
